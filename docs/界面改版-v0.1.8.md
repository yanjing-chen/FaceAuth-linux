# v0.1.8 设置页设计

## 设计布局

窗口宽屏时，设置页与录入页统一为双栏视图：

- 左列：识别方式（模式、活体）→ 摄像头（RGB、IR、采样检查、扫描设备）
- 右列：已录入人脸（列表、单独删除、删除全部）→ 系统认证（sudo、GDM、su、TTY、polkit）
- 顶部：页面标题与刷新状态；底部：IR 实验性活体简短提示

下拉选择按钮直接显示已选值；在弹出菜单中显示完整设备路径和检测类型，不对设备分类做未经验证的猜测。

## 运行

只需关闭现有 FaceAuth GUI，在源码目录运行 `bash scripts/launch-gui.sh`。
**不要执行 install-system.sh 或卸载系统服务。**

系统服务继续使用已通过认证实测的 v0.1.6；新版只替换用户态显示代码。
