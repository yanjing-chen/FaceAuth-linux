# FaceAuth v0.1.8 界面重设计

本版只改 GTK4 用户界面。使用用户在 Ubuntu 26.10 / GNOME 51 上实机验收通过的 v0.1.6 守护进程、PAM 模块和认证配置，**不要再运行 install-system.sh/uninstall-system.sh**。

- “录入 / 测试”页采用左侧实时画面，右侧录入、测试及明确结果的布局。保留实时跟踪角框与持续预览。
- “设置 / 管理”页采用居中限宽的 libadwaita PreferencesGroup，不再铺满整个窗口。
- 设备下拉列表继续完整显示名称与设备路径，按钮保留选中值。
- 录入成功/失败和识别成功/失败均用 Adw.AlertDialog 提醒；状态仍在右侧保留。
- 系统场景开关、PAM 认证、daemon、模型推理和模板格式**没有变更**。

运行：`bash scripts/launch-gui.sh`。需要关闭旧 GUI 窗口，否则 GApplication 可能复用旧实例。

只更换 GUI 源码，不改变系统服务。
